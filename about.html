关于我

我是李志军，目前在 AI4EDA（AI for Electronic Design Automation）方向工作，关注 LLM Agent、贝叶斯优化、Skill 自进化在 IC 设计中的应用。

当前项目：IC Agent OS —— 基于 OpenCode + SkillOpt 调度器的通用 IC 设计优化引擎。目标是在 AnalogGym 标准 benchmark 上，以统一架构跑通模拟 IC 全流程优化，平均仿真次数优于现有方法 50% 以上。

研究方向：

  • Agent Harness 工程 —— Harness 自进化、Skill 优化、Trace 诊断
  • 模拟 IC 自动化设计 —— Forge→Measure→Refine 闭环优化
  • 贝叶斯优化 + LLM 混合决策
  • EDA 工具接口标准化（Adapter 协议）
